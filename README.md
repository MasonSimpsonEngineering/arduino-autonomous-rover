# arduino-autonomous-rover
An Arduino-based autonomous mobile robot featuring ultrasonic obstacle detection, differential-drive motor control, and embedded C++ programming.
## Project Overview 
This Project focuses on designing, building, and programming an autonomous ground rover capable of detecting and avoiding obstacles without human intervention 
The Rover will serve as a hands-on engineering platform for learning embedded systems, robotics, motor control, electronics, and autonomous navigation. 
## Project Objectives 
- Design and assemble a functional robotic rover.
- Program an Arduino microcontroller using C++.
- Implement differential-drive motor control.
- Integrate ultrasonic distance sensing.
- Develop autonomous obstacle-avoidance algorithms.
- Test and evaluate navigation performance.
- Document the engineering process.
